 E-Commerce Product and Customer Analytics Dashboard

# Overview
An interactive analytics dashboard built using Python and Streamlit
to explore e-commerce sales, customer behavior, product performance,
order payments, delivery performance, and customer reviews.

## Objectives
- Analyze sales and order trends.
- Identify top-performing product categories.
- Explore customer purchasing behavior.
- Understand payment patterns.
- Evaluate delivery performance and customer reviews.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit
- GitHub

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

## Dashboard Pages
1. Executive Overview
2. Product Analytics
3. Customer Intelligence
4. Orders & Payments
5. Delivery & Reviews
